# Ahmed Cheruvattam — Portfolio

A static portfolio with an About Me homepage, compact project icons, and a dedicated CV project landing page.

## Open locally

Open `index.html` in your browser. Select the CV project icon to open `projects/tool-tip-tracking.html`. Use “All projects” to return home.

## Publish with GitHub Pages

Upload the contents of this folder to your portfolio repository, keeping the `projects` folder structure. Configure GitHub Pages to serve the root folder of that branch. There is no build step or dependency installation. Relative links work for both account-level and repository-level GitHub Pages sites.

## Content

The CV page summarizes the team repository at https://github.com/yxLuo06/Computer-Vison-Course-project, reviewed October 21, 2026. Proposed methods are labeled as in progress, team members are credited, and the inline SVG illustrations are concepts rather than experimental results.
